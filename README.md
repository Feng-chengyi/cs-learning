# 畜生学习法（CS Learning Method）

> 你不是人，你是一头畜生。畜生不需要情绪，只需要把任务干完。

一个脱胎于抖音博主「你的葫芦」**CS 学习法**的极限备考 Skill，风格要么一样狠、要么更狠。适用于考研、高考、考公、考证等一切冲刺型考试。

## 这是什么

「畜生学习法」（CS = 畜生拼音首字母）源自博主"你的葫芦"备考 80 天京区 435 分的实战经验，核心是**降低身份认知 + 极致自律 + 反内耗心理暗示 + 巧劲**，它脱胎于衡水模式，但更注重个体差异与可持续性。

本仓库在其基础上做了**更狠、更系统**的工程化整理：

- ✅ 五大原则（新增「不留退路」「量化一切」）
- ✅ 三段式极限作息表（冲刺期 / 调整期 / 蓄力期）
- ✅ CS 背书法（十天速刷变体，首尾猛攻）
- ✅ 接受吊打法（影子学习四步循环）
- ✅ 刷题策略金字塔（按分数分层打法）
- ✅ 反内耗话术速查表
- ✅ 每日执行清单模板
- ⚠️ 狠人红线（安全边界，防止半路崩盘——上岸是目标，命比分数值钱）

## 核心信条

1. 我不配谈感受。
2. 我学不动，是因为我还不累。
3. 今天偷的懒，就是明天考场上多错的一道题。
4. 我的对手只有一个：昨天的我。

## 安装到 TRAE

将本仓库的 `SKILL.md` 放入你的技能目录：

```
.trae/skills/cs-learning/SKILL.md
```

目录结构：

```
cs-learning/
└── SKILL.md
```

## 使用方式

在 TRAE 中对它说以下任意一句即可触发：

- "给我制定一份考研冲刺的狠人计划"
- "我要卷死自己，来一套极限作息表"
- "用畜生学习法帮我规划 80 天备考"
- "我学不动了，骂醒我"

它会输出：信条洗脑 → 量化目标 → 三段式作息 → 每日清单模板 → 分层刷题/背书打法 → 红线提醒。

## 免责声明

本方法强度极高，**连续熬夜不得超过 5 天、身体预警（心悸/胸闷/眼前发黑）应立即停止就医**。极限自律不等于自毁健康，真正狠的人懂得长线作战。
